## User

もともとの英語の再帰はどういうニュアンスだったっけ?

## Assistant

英語で「再帰」に対応する中心語は recursion / recursive です。
もともとのニュアンスは、かなり素朴に言えば、

戻ってくること
再び現れること
前の地点・状態・構造へ返ってくること

です。
語源的には、re- が「再び／後ろへ／戻って」、currere がラテン語系で「走る」に近い意味なので、
recur はもともと run back / come back、つまり「走って戻る」「再び起こる」という感じです。
だから、英語の recurrence は今でも、
同じことが再び起きること周期的に現れること再発反復回帰
の意味で使われます。
たとえば、
recurring event
なら「繰り返し予定」。
recurrence relation
なら「前の値を使って次の値を決める関係式」。
recursive function
なら「自分自身を呼び戻す関数」。
なので、英語の元の感覚としては、単なる repeat よりも『戻ってくる』『再び立ち現れる』が強いです。
あなたの文脈に合わせると、こう整理できます。
repeat  同じことをもう一度行うrecur  同じこと・同じ構造が再び現れるrecurrence  再び現れる性質・周期的に戻ることrecursion  自分自身の構造へ戻って処理することrecursive  自分自身を含む／自分自身へ戻る性質を持つ
だから、L-system の例でいうと、かなり自然です。
種 → 枝葉 → 種 → 枝葉 → ...
これは単に「同じ作業を繰り返している」というより、

ある構造が、結果の中に再び現れる

という意味で recursive / recurrent です。
つまり、「再帰」の英語的な芯は、

帰ってくる
また現れる
前の構造が次の構造の中に戻ってくる

です。
あなたが言っている「後の先を取る」「後から反応する」というニュアンスは、react / response / feedback 側の語感も混ざっています。
でも recursion / recurrence 自体の古い芯は、どちらかというと、

戻ること、再び現れること

です。
なので本文では、

英語の recursion / recurrence には、単に繰り返すというより、「戻ってくる」「再び現れる」という感覚がある。サイバーの技としての再帰は、この「返ってくる働き」を扱う。種が枝葉を生み、枝葉がまた種を生むように、前の構造が後の構造の中へ戻ってくる。

と書くと、かなり筋が通ります。
