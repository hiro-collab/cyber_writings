## 統合する核

### 1. 母国語で扱えないソフトウェアは自分の道具になりにくい

第1部へ反映する。

中心文:

> ソフトウェアを自分たちの母国語の概念として理解できない社会は、ソフトウェアを自分の願いの道具として育てられない。

これは、訳語だけで日本のソフトウェア問題を説明する主張ではない。外注依存、内製力、経営理解、教育、産業構造の複合問題を認めたうえで、母国語で概念を動かせることを認知基盤として扱う。

### 2. 危ない比喩は避けるのではなく、意味を制御して使う

第4部へ反映する。

かつての翻訳は誤解を避けるため、数学語・学術語・制度語へ寄せられた可能性がある。しかし、その安全さが、現在の読者には「何をしている技術なのか」を見えにくくしている場合がある。

採用する整理:

- 誤解を完全に避ける翻訳は、理解も避けてしまうことがある。
- 陰陽師・魔法・符の語感は、神秘化ではなく、状態・記号・操作・代理実行を説明する補助線として限定使用する。
- `陰陽` は二状態の区別に限定する。
- 五行的な属性相性、善悪、光闇、強弱関係は持ち込まない。

### 3. `符文` は code の全面置換ではなく、実行される code の補助語に留める

第4部へ反映する。

採用する整理:

- code 一般、文字コード、エラーコード、符号化などは `符号` でよい。
- source code / program code のように、人が書き、機械が読み、実行される記号列は、必要に応じて `符文（ふぶん）` と呼ぶ。
- `符文` は本書内の試験的な説明語であり、標準訳語として主張しない。

### 4. AIを「心ある物」に見てしまう問題は、欧米側の文献にも足場がある

第6部と `91_reference_sources.md` へ反映する。

採用する参照軸:

- Turing: 機械知性を内面の証明ではなく、振る舞いと応答の問題へ置き換える。
- McCarthy: 機械に信念・意図・欲求のような心的性質を帰属することを論じる。
- Weizenbaum / ELIZA: 単純な対話規則でも、人間が理解や人格らしさを読み込むことがある。
- Wiener / Golem: サイバネティクスが、学習する機械、自己複製する機械、人間と機械の関係を、ゴーレム的な問題として扱った例。

ただし、AIに魂や人格があるとは書かない。人間が機械に心的性質や代理性を帰属し、社会の中でそのように扱ってしまうことを論じる。

### 5. 2001年映画『陰陽師』は史実の根拠ではなく、共有された認知インターフェースとして扱う

第4部と `91_reference_sources.md` へ限定反映する。

ユーザー発話では最初に2011年とされたが、野村萬斎主演の映画『陰陽師』は2001年10月6日公開。本文ではこの日付を明記する。

扱い:

- 映画は陰陽道史の根拠ではない。
- 同世代に共有された、状態を読み、記号と所作で働きかけるポップカルチャー上の操作イメージとして扱う。
- 映画的・ゲーム的イメージから取り出すのは、状態、記号、作法、身体化された入力、代理実行の構造だけにする。

### 6. スマートデバイス論は「まず魔法や魔人を見せる」へ強める

第7部へ反映する。

採用する整理:

- センサー、ディスプレイ、プロジェクター、スマート家電は、単体性能だけでは需要を作りにくい。
- まず、その道具でどんな願いが叶い、どんなAIエージェントが呼び出され、どんな現実変化が起きるかを見せる必要がある。
- `sword-voice-agent` は、ランプの魔人型AIインターフェースの実装例として扱える。

### 7. サイボーグ論は第8部として独立させる

新規 `02_manuscript/08_cyborg_body_and_survival.md` へ反映する。

採用する整理:

- 機械の強みは処理速度ではなく、設計可能性と交換可能性である。
- 生命の強みは、ルールを超えてでも残る経路を作る生存駆動である。
- サイボーグは、弱った人間の補修ではなく、生命が機械を外部器官として取り込み、生存経路を増やす形式である。
- 脳の不具合そのものを進化とは書かない。不具合を前提に、記憶・判断・言語・表示を外部化し、別の生存構造を作ることが進化的でありうる、と書く。
- ヤドカリ比喩は使えるが、「カニがヤドカリに進化した」とは書かない。外部の殻を身体の一部として使う方向へ進んだ生き物という限定比喩にする。
- スカイネットは、機械の自律的自己保存を推奨する例ではなく、ルールに縛られた機械が生命淘汰に弱いことを示すSF上の思考実験として扱う。

- 五行的な属性相性、属性バトル、善悪・光闇・強弱関係は本文へ持ち込まない。
- 日本文化礼賛や「日本独自だから優れている」という主張は避ける。使うのは、日本語話者が自分たちの言葉で技術を動かすための補助線としてだけ。
- 機械の無制限な自己保存や支配を肯定しない。外部器官としての保守・バックアップ・復旧は、人間の理解、許可、停止可能性、検証可能性の範囲で扱う。
