# X weighted character countの要点

## 採用する規則

- 投稿本文の上限は weighted character count で280。
- 日本語・中国語・韓国語などのCJK文字は通常2として数える。
- ラテン文字、一般的な英数字、句読点の多くは1として数える。
- 絵文字は、ZWJで結合された複合絵文字を含め、1つの絵文字として2で数える。
- 有効なURLはt.co短縮URLとして、元の長さにかかわらず23で数える。
- XはUnicode Normalization Form C（NFC）へ正規化して扱う。
- 添付メディアは、公式クライアントで添付する限り本文の文字数へ加えない。

## 実装方針

最終判定には、Xが案内しているオープンソースの`twitter-text`を使用する。

単純な`len()`やJavaScriptの`string.length`は、次の理由で最終判定には使わない。

- 日本語と英数字で重みが異なる
- 複合絵文字が複数コードポイントから成る
- URLが固定長へ置き換わる
- Unicode正規化の影響がある

## 安全余白

Xの上限は280だが、編集時の追記、投稿欄での自動メンション、番号付けなどを考慮し、このSkillでは260以内を安全域とする。
